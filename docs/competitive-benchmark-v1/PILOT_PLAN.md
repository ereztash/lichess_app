# PILOT_PLAN

## Pilot A — apparatus (n=12)

Purpose: verify that the measurement can fail cleanly.

- 6 DL / 6 provisional BAA, stratified as confirmatory.
- run T0–T5 only.
- at least 2 deliberate research-infrastructure failure fixtures before humans: expired credential and broken launcher.
- positive controls for blinding: one branded output must be detected and rejected.
- positive control for rubric: two deliberately vague/overclaiming answers must score lower than bounded answers.
- verify timeout, autosave, timestamp order and engine-after-freeze invariant.

Pass criteria: all hard gates; ≥80% T5 window adherence; research-caused failure ≤10%; rubric alpha ≥0.80 (one clarification allowed at 0.67–0.79); item floor/ceiling within limits.

## Pilot Q — BAA qualification (n=18 fresh)

9 Aimchess Premium, 9 Chess.com Diamond. Same T0–T5, same 75-minute total exposure. Select using frozen rule in preregistration. Do not choose based on satisfaction, brand familiarity or price. Archive loser; do not hide its result.

## Dry-run adversarial audit

Before pilot, one researcher argues for DL and one for incumbent. Each must identify:

- one data path that could convert missing to success;
- one moderator phrase that could change performance;
- one input asymmetry;
- one pricing/access asymmetry;
- one item-selection path that knows the treatment output.

Launch only when each attack has a tested control or an explicit invalidity trigger.

## What pilot cannot do

No power claim, no product win, no threshold tuning, no motif selection by effect size, no change to DL.
