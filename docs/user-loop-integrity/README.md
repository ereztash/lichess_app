# User loop integrity — the decision loop, driven rather than read

A mission workspace, not a new governance layer. Where an existing authority owns a question, these
files point at it instead of answering it again.

| file | what it owns |
| --- | --- |
| [`BASELINE.md`](BASELINE.md) | the SHA, the verification numbers, and how the app was driven. A snapshot: it does not move when later counts do. |
| [`LOOP_CORPUS.md`](LOOP_CORPUS.md) | the loops audited, and the step each one stops at |
| [`REPO_CROSSWALK.md`](REPO_CROSSWALK.md) | the external `User Loop Integrity` model classified against this repository's own laws |
| [`CONTRADICTIONS.md`](CONTRADICTIONS.md) | seven places where a built screen disagreed with an authority this repository holds — and what was **not** a contradiction |
| [`FALSIFICATION_REGISTER.md`](FALSIFICATION_REGISTER.md) | every claim with what reverses it, and every open question with its trigger |
| `evidence/` | the walk scripts' JSON and the screenshots taken at each boundary |

## What is NOT here, on purpose

- **No new law.** The classification is `ALREADY_REPO_NATIVE`; the register that owns repo-wide laws
  is [`../consolidation-research/REPO_NATIVE_OPERATING_SYSTEM.md`](../consolidation-research/REPO_NATIVE_OPERATING_SYSTEM.md)
  and it is not amended by this mission.
- **No second contradiction register.** `CONTRADICTIONS.md` here is scoped to the decision loop's
  surface and numbers its rows `ULI-X-nn` so it cannot be confused with the corpus-wide one.
- **No new telemetry.** `docs/ACQUISITION_EVIDENCE.md` already asks every question this mission
  raised about continuation, and the answer was that its `continue` row was mechanically
  unreachable — not that it was missing.
- **No answer to where a stranger's second decision comes from.** That is `OWNER-REQUIRED`.
