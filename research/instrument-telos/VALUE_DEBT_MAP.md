# Value-debt map

Sequences, not single actions. A product can hold individually defensible costs whose accumulation
is indefensible. **A larger evidence counter is not repayment** unless it changes something useful
for the player.

## Path A — cold arrival → first prospective decision → reveal

| | |
|---|---|
| Actions paid | read the front door, type a username, wait ~80 s, place a move, submit, state a confidence |
| Evidence gained | five games scored, one prospective decision with a stated confidence |
| Payoff received | the import finding with both n's, then a full reveal naming what the move cost, what it did not establish, and a question |
| Unpaid stretch | **none longer than one action** |
| Next promised payoff | the next decision |
| Certainty | certain |

**This path has essentially no value debt.** It is the strongest sequence in the product and it is
the one a cold user meets first.

## Path B — reveal → next decision → accumulation

| | |
|---|---|
| Actions paid | 1 tap to continue, then 3 to 4 taps per decision |
| Evidence gained | one row per decision; one **scored** row per seven |
| Payoff received | a full reveal after every decision |
| Unpaid stretch | **none for the reveal**; unbounded for the counter |
| Next promised payoff | the first claim at 60 scored |
| Certainty | conditional, and stated as conditional |

Two different debts run on this path at once, and separating them is the whole of the analysis.
The **per-decision debt is zero**: every decision returns a reading. The **threshold debt is
long**: measured, 26 taps moved the counter from 0 to 1 of 60.

## Path C — ordinary play → repeated instrumentation → detector readiness

| | |
|---|---|
| Actions paid | measured: 34 taps over 6 decisions, of which 2 carried the extra questions |
| Evidence gained | 1 admissible scored decision |
| Payoff received | 6 reveals |
| **Unpaid stretch** | **the longest in the product.** From the first decision to the first claim, with the counter as the only thing that moves and `ASK_RATE` making it move at a seventh of the rate the player's effort suggests |
| Next promised payoff | a hypothesis, not a finding |
| Certainty | conditional on 60, and conditional again on a split existing |

## Path D — blitz → post-game reading → more blitz

| | |
|---|---|
| Actions paid | a whole game, plus a confidence question about one move in seven |
| Evidence gained | **nothing until the game ends**; then the whole game at once |
| Payoff received | the post-game reading, typically the honest negative *"לא מצאתי במשחק הזה לבדו משהו שכדאי להסיק ממנו עליך"* |
| Unpaid stretch | one whole game, and **infinite if the player abandons it** |
| Next promised payoff | `עוד 30 משחקים לפחות יאפשרו בדיקה ראשונה` |
| Certainty | conditional |

The all-or-nothing write is the sharpest single defect on this path. A player who plays eleven
moves and closes the tab has produced nothing, has been told nothing about that, and will see the
record page say they have not played.

## Path E — historical import → retrospective finding → prospective evidence

| | |
|---|---|
| Actions paid | a username and about 80 seconds |
| Evidence gained | 240 scored positions, none admissible to discovery |
| Payoff received | a finding with two n's, and a sentence naming exactly what those games cannot hold: *"החלטה שתרשמו מוסיפה מה שהמשחקים האלה לא מחזיקים: ביטחון שהצהרתם לפני שהמנוע דיבר. משחק שכבר שוחק לא יכול לייצר את זה, בשום כמות."* |
| Unpaid stretch | none |
| Next promised payoff | named explicitly, in the same sentence |
| Certainty | the finding is certain; the prospective promise is conditional |

**This is the best value contract in the product.** It states the cost, the payoff, and the exact
reason the cheaper path cannot substitute, in one sentence, at the moment the cost is proposed.
Everything else in the product is being judged against a standard the product itself has already
met once.

## Path F — returning user with insufficient evidence

| | |
|---|---|
| Actions paid | opening the app |
| Evidence gained | none |
| Payoff received | one blocker named, one next step, `למה אנחנו אומרים את זה?` |
| Unpaid stretch | none |
| Certainty | n/a |

## Path G — negative result → request for more evidence

| | |
|---|---|
| Actions paid | reading it |
| Evidence gained | none |
| Payoff received | a true statement: *"בדקנו את כל החלוקות שיש לנו, ואף אחת מהן לא הפרידה בין ההחלטות שלך"*, which refuses to call a null a shortage |
| Unpaid stretch | none |
| Next promised payoff | more decisions may separate what this n could not |
| Certainty | conditional, and stated so |

## The longest unpaid interval

**Path C**, from the first prospective decision to the first claim.

It is the longest not because any single action is unpaid, but because it is the only path where
the thing the product asks the player to build, the discovery population, advances at a rate the
product does not disclose. Measured: 26 taps for 1 of 60. Everything else on that path pays per
step.
