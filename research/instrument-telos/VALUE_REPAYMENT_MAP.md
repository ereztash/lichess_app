# Value-repayment map

Every surface where the product repays measurement cost. For each: could this output exist without
the user having paid the earlier epistemic cost, and is it reachable now?

| Surface | Could it exist without the cost? | Differentiated? | Availability |
|---|---|---|---|
| Historical import finding | **Yes.** Any engine can score old games. The finding names both n's, which is better than most, but nothing about it requires the player to have paid anything | no | `AVAILABLE_NOW` |
| The sentence that names what import cannot buy | **No.** It is a claim about what the retrospective corpus structurally lacks, and only a product that has drawn that boundary can say it | **yes** | `AVAILABLE_NOW` |
| Reveal: what the move cost | Yes, any engine | no | `AVAILABLE_NOW` |
| Reveal: inference limits, *"רק מהלך אחד נרשם כנשקל"*, *"הפרש של 0.06 רגלים הוא בתוך רעש ההערכה. זו לא טעות"* | **No.** These are statements about what this record can and cannot support. They require the commitment-before-verdict protocol to be meaningful | **yes** | `AVAILABLE_NOW` |
| Reveal: the next question anchored to the player's own words | **No.** It reads `statedUnknown`, which only exists because the player was asked | **yes** | `AVAILABLE_NOW`, on instrumented decisions only |
| Reveal: `מה נצבר` | partly | no | `AVAILABLE_NOW` |
| Process vs engine distinction, the whole front-door promise | **No** | **yes** | `AVAILABLE_NOW` as a claim; the evidence behind it is `REQUIRES_N` |
| The named alternative, scored | **No.** Requires a move named before the engine spoke | **yes** | `AVAILABLE_NOW`, behind the `פרטי הניתוח` disclosure |
| Counterfactual four-way reading | **No** | **yes** | `REQUIRES_N`: 30 probed, so roughly 86 decisions |
| Calibration gap | **No.** The product's single strongest differentiator | **yes** | `REQUIRES_N`: 60 scored, measured at 1 per 26 taps |
| Candidate finding | **No** | **yes** | `REQUIRES_N`: 60 |
| Negative state, *"בדקנו את כל החלוקות שיש לנו"* | **No.** A null is only meaningful against a pre-registered set of splits | **yes** | `AVAILABLE_NOW` |
| Post-game blitz reading | partly | no | `CONDITIONAL` on finishing the game |
| Blitz shortfall, `עוד 30 משחקים` | no | no | `AVAILABLE_NOW` |
| Rule or player-owned question | **No** | **yes** | `FEATURE_FLAGGED` |
| Practice / drill | **No** | **yes** | `FEATURE_FLAGGED` |
| Prompted check / transfer | **No** | **yes** | `FEATURE_FLAGGED` |
| Ordinary-play observation of a rule | **No** | **yes** | `FEATURE_FLAGGED` |

## The shape of it

**Differentiated payoffs that are `AVAILABLE_NOW`: five.** The inference limits, the import
boundary sentence, the anchored question, the scored alternative, and the negative state. All five
arrive within seconds of the cost that earns them.

**Differentiated payoffs that are `REQUIRES_N`: three.** The counterfactual reading, the
calibration gap, the candidate.

**Differentiated payoffs that are `FEATURE_FLAGGED`: four.** The entire learning half.

The strongest repayment surface is **the reveal's inference limits**, because it is differentiated,
immediate, unconditional, and repeats on every single decision. It is also the surface least likely
to be recognised as a payoff, because it is phrased as a list of things the product will not claim.
