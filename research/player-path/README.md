answers, and built a sentence.

## The one-line result

The favoured hypothesis was refused by the run: an entry frame promising personal inference is an
outcome claim the evidence ceiling forbids, and an entry frame built on a player's aspiration is how
rating re-enters as a denominator. The permitted substitute was already in the repository, unrendered
and used twice as a caveat.

## The standing debt

Whether a player told what this product uniquely does judges the next act worth taking is `FIELD` at
R6, and no build in this lane closes it. `FIELD_TEST_PROTOCOL.md` is how it would be closed.
